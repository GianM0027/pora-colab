# PoRA exercises, Colab-ready

Copies of notebooks from [StanfordASL/pora-exercises](https://github.com/StanfordASL/pora-exercises) (Principles of Robot Autonomy) with one added first cell: on Google Colab it clones the original repo, moves into the notebook's folder so helper files and data are found, and installs missing packages. Everything else is unchanged; all credit to the original authors.
